# nidrle.

Personal website for Esy Nidrle's social skills coaching for individuals and companies.

## Preview

This is a static website with no build dependencies. Run a static server from this directory, for example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.

## Deploy

Publish this directory using any static hosting provider. `index.html` is the entry point and `assets/` contains the portrait. Domain and email DNS are configured separately.
